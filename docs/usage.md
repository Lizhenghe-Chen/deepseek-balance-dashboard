# 使用与账户

> 返回 [README](../README.md) · 相关：[FAQ](./faq.md) · [数据模型](./data-model.md)

## 🔁 多账户 / 换 Key

1. 点顶栏 `⚙️`，面板顶部显示**当前账户**（名字 + Key 掩码 + 指纹 + 历史条数），下面列出所有账户的历史概况。
2. **换 Key 不再询问、也不清空任何东西**：
   - 粘贴一个**已存在**的 Key → 直接切回它那份历史；
   - 粘贴一个**新** Key → 新建一份档案，从这一刻开始记录，其它账户原样保留。
3. 每个账户可以点名字**重命名**（默认用导入 CSV 时的 `user_id`，没有就用指纹前 6 位），也可以逐个**删除**（点两次确认）。
4. 点右上角 `✕`（或按 `Esc`、点面板外的遮罩）只关闭面板，什么都不改；「清除 Key」只清除 Key、不删任何历史，重新粘贴对应 Key 即可继续。
5. 最多保存 **5 个账户**，每条档案保留最近 **60 天**。

> ⚠️ **同一账户的多个 Key 共享同一个余额池**。它们各自独立记一份观测序列是没问题的（不会再互相做差产生假消费），但**不要把它们的消费相加**。如果你要的是「一个账户一个总额」，就只留一个 Key 的记录。

> 币种不同会按 `指纹|币种` 各存一份，CNY 与 USD 的历史不会混算，也不会互相覆盖。

## 💾 历史备份与迁移

- 顶栏「导出历史数据」把**全部账户**与官方用量写成一份 JSON；「导入历史数据」按档案合并（同一天以时间戳并集为准），旧版单档案 JSON 同样可导入。
- 数据按**来源（origin）**隔离：在线版与本地版（`file://`）互不相通，`https://bunnychen.top/…` 与 `https://<用户名>.github.io/…` 也各自独立。跨设备 / 跨浏览器请走导出 / 导入。
- 想从零开始：在 `⚙️` 里删掉对应账户，或清掉浏览器的 `ds_history_v3`。

## 🧾 官方用量 CSV

1. 打开 <https://platform.deepseek.com/usage> →「用量信息」→ 选时间范围 → **导出**；
2. 解压得到 `amount-*.csv` 与 `cost-*.csv`；
3. 在页面「官方用量」面板点「导入 CSV」，可多选两个文件，也可以直接把文件拖进面板。

导入后：

- 已过去的整天改用官方日成本（`本月消费`、日均、预测都会跟上），副标题标注「官方 N/M 天」，避免整月被误读为精确值；
- 面板给出官方本月 / 今日成本、缓存命中率、请求数、分模型成本，以及「官方 vs 观测」的对账差；
- 每次导入单独成一条（文件名 / `user_id` / Key 名称 / 日期范围 / 金额 / 导入时间），可删除，删除后 8 秒内可撤销；
- 文件里的 `api_key` 列**不会被读取**，也不会落盘。

> 同日多行怎么加、账户不匹配怎么办、重复导入是否翻倍等细节，见 [FAQ](./faq.md)。

## 🔔 低余额提醒

在 `⚙️` 面板里填阈值并点「开启 / 更新」，浏览器会请求通知权限；余额跌破阈值时发一次桌面通知，回升后再跌破会重新提醒。

限制（页面会如实标注）：只在页面打开时生效；后台标签页可能延迟到约 1 分钟；手机锁屏 / 关闭浏览器不会触发；iOS Safari 需要把页面「添加到主屏幕」且走 Service Worker，本页用的是普通 `Notification`。想要「关掉浏览器也能提醒」，只能用服务端方案（例如 GitHub Actions 定时轮询）。
